# Raw Data

Esta pasta contém as referências aos dados brutos utilizados no projeto Eco_Raiz_360.

Os arquivos originais são armazenados no Google Drive devido ao grande volume de dados e não são versionados diretamente neste repositório.

## Bases de dados

| Dataset | Fonte | Descrição |
|---|---|---|
| EMBRAPA Dados Agropecuários | EMBRAPA | Dados relacionados à produção e atividade agropecuária |
| IBGE Bioma Predominante por Município | IBGE | Identificação do bioma predominante por município |
| IBGE Malha Municipal | IBGE | Dados geográficos e limites municipais |
| IBGE PAM Soja e Cana | IBGE | Produção agrícola de soja e cana-de-açúcar |
| INMET Dados Históricos Climáticos | INMET | Dados históricos meteorológicos e climáticos |
| MapBiomas Cobertura e Uso da Terra | MapBiomas | Dados de cobertura e uso da terra |
| MapBiomas Solo | MapBiomas | Dados relacionados às características e classificação do solo |
| SEEG Emissões GEE | SEEG | Dados de emissões e remoções de gases de efeito estufa |
